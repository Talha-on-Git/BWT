# 💬 Random Quote Generator

A responsive and interactive web app that displays a **random quote** each time it’s opened or refreshed.  
Built with **HTML, CSS, and JavaScript**, this project connects to an external quote API to deliver inspiring, funny, or thoughtful quotes with just one click.

🌐 **Live Demo:** [Random Quote Generator](https://talha-on-git.github.io/Random-Quote-Gen/)

---

## 🚀 Features
- 🧠 Fetches quotes dynamically from a public API  
- 🔁 “Next Quote” button to instantly load a new random quote  
- 📋 “Copy Quote” button to copy the quote text to your clipboard  
- 💡 Minimalist and mobile-friendly design using pure HTML & CSS  
- ⚡ Smooth and fast — no frameworks or dependencies  

---

## 🛠️ Tech Stack
- **Languages:** HTML, CSS, JavaScript  
- **Data Source:** Public Quote Library API  
- **Hosting:** GitHub Pages  

---

## 📖 How It Works
1. The app automatically fetches and displays a random quote on load.  
2. Clicking **Next Quote** fetches another random quote from the API.  
3. Clicking **Copy Quote** copies the quote text to your clipboard for easy sharing.
